This branch, `automation-project/implementation`, is where the T3 Automations, Connections, and Voice work is built. `main` on this fork mirrors upstream and never receives our merges.

- Open PRs with `gh pr create --base automation-project/implementation`.
- Research, mockups, and the full workflow rules live in the private repo `I-am-drunk/devin-decompile` (`WORKFLOW.md`). Nothing from that repo is committed here.
