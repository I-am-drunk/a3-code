Placement decision: Automations is a top-level sidebar entry, placed directly under the search/toolbar row and above the thread list (the only other top-level navigation in T3 is the footer utility row: Settings, Pull Requests, Usage). Rationale: an automation can target several projects, fires without a user turn, and produces runs that are not threads — so it does not belong inside a project's thread grouping (there is no per-project section in the default sidebar; grouping is by pinned/active/snoozed/settled state, Sidebar.tsx:3384-3398). It also should not be buried in the footer, because its badge carries live state (running / unread / failed) that the user must see at a glance. Four states shown per theme; the badge reuses --update-surface for running and --error-surface for failures, both already in T3's palette.
